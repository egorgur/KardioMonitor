# Значительное превышение нормы тренировочных минут

## Требование

1. Врач должен иметь возможность индивидуально для каждого пациента задавать верхний порог количества тренировочных минут за сутки. Порог задаётся в минутах, а не в процентах от суточной нормы.
2. Система должна выявлять значительное превышение, если фактическое количество тренировочных минут пациента за сутки больше верхнего порога, заданного врачом для этого пациента. Равенство порогу не считается превышением.
3. Проверка превышения должна выполняться при каждом поступлении данных с учётом обновлённого количества тренировочных минут за соответствующие сутки, без ожидания окончания дня.

4. При выявлении превышения система должна создавать оповещение врачу и уведомлять пациента.
