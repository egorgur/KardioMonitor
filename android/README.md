# KardioMonitor — Android-приложение

Прототип приложения для наблюдения за пациентами, проходящими реабилитацию после
инфаркта миокарда. Читает данные с фитнес-браслета **Xiaomi Mi Smart Band 6 (XMSH15HM)**
напрямую по Bluetooth LE, без облака Xiaomi.

> Данные бытового браслета не являются медицинскими измерениями и подходят для
> наблюдения за динамикой, но не для диагностики.

## Возможности

- Привязка браслета по QR-коду клиники или вводом MAC-адреса и ключа.
- Авторизация по протоколу Huami 2021 (прошивка 1.0.6.10+).
- Заряд браслета, шаги за сегодня, пульс в реальном времени (для тренировок).
- Поминутная история пульса и шагов в локальной базе, синхронизация по кнопке и
  в фоне каждые 30 минут.
- Настройка частоты фонового измерения пульса (1, 5, 10, 30 мин, выкл).
- Итоги дня: шаги, пульс ср/мин/макс, покрытие пульсом, график пульса за сутки,
  шаги по часам, навигация по дням.

## Требования

- JDK 21, Android SDK (platform 36), Gradle wrapper в репозитории (9.4).
- Телефон с Android 8.0+ и BLE. Эмулятор для работы с браслетом не подходит.
- Ключ авторизации браслета — см. корневой [README](../README.md), раздел
  «Получить ключ авторизации».

## Сборка и запуск

```bash
./gradlew assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug         # установить на телефон, подключённый по adb
./gradlew testDebugUnitTest    # модульные тесты
./gradlew lintDebug            # статический анализ
```

QR-код для пациента (из корня репозитория):

```bash
python tools/make_qr.py --mac E7:19:F3:6C:04:9E --out band.svg   # ключ — из MIBAND_AUTH_KEY
```

Перед подключением на телефоне нужно закрыть Mi Fitness или отключить ей разрешение
«Устройства поблизости»: браслет держит одно соединение. Для стабильной фоновой
синхронизации: «Настройки → Приложения → KardioMonitor → Батарея → Без ограничений».

## Структура

```
android/
  CLAUDE.md          # инструкции для ИИ-агента (Claude Code)
  .claude/           # настройки агента: hooks, skills проекта, подагент-ревьюер
  docs/              # архитектура, домен, правила кода, тесты, протокол, ADR
  app/src/main/java/ru/kardiomonitor/
    ble/             # GATT-клиент, протокол Huami 2021, команды Mi Band 6
    data/            # учётные данные браслета, настройки, SQLite-история
    ui/              # экраны, графики, тема
    BandManager.kt   # общий сеанс связи с браслетом (экран + фон)
    SyncWorker.kt    # фоновая синхронизация (WorkManager)
  app/src/test/      # тесты протокола, разбора данных и архитектурные (architecture/)
```

Целевая структура — по контекстам и вертикальным слайсам (`features/band/…`,
`features/monitoring/…`), см. [docs/architecture.md](docs/architecture.md). Текущий
код переносится в неё поэтапно.

## Ограничения прототипа

- Подтверждение выгрузки браслету не отправляется — данные остаются и для Mi Fitness
  ([ADR-0002](docs/adr/0002-keep-history-on-band.md)).
- Данные о сне не расшифрованы.
- Нет передачи данных врачу, подписанной release-сборки и иконки приложения.
- Ключ браслета хранится в обычных SharedPreferences (план — Android Keystore).
