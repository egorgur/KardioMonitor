# ADR-0003: Одно соединение с браслетом на всё приложение

- Статус: принято
- Дата: 2026-10-09

## Контекст

Браслет держит только одно BLE-соединение. Экран (подключение по кнопке, пульс
сейчас) и фоновая синхронизация могут захотеть подключиться одновременно.

## Решение

Все сценарии работают через один объект сеанса связи (сейчас `BandManager`, по
целевой архитектуре — порт `features.band.api.BandConnection`). Подключение и
синхронизация выполняются по очереди (mutex). Фоновая синхронизация использует
открытое соединение, если оно есть; иначе подключается и отключается сама. При
сворачивании приложения ручное соединение закрывается, если не идёт измерение
пульса в реальном времени.

## Последствия

- Сценарии не мешают друг другу.
- Ни один слайс не создаёт `GattClient` сам.

## Отвергнутые варианты

- Отдельные соединения для экрана и фона — второе подключение падает.
- Постоянное соединение в foreground-сервисе — лишний расход батареи браслета и телефона.
