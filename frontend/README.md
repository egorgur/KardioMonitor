# KardioMonitor — панель клиники (демо)

React-приложение, которое показывает данные, присланные телефонами пациентов:
список пациентов, «пульс сейчас» (обновление каждые 2 с), итоги дня и графики пульса
по минутам и шагов по часам. Дневная статистика пульса показывает минуты в интервалах
`< 40`, `40–49`, …, `120+`; точки графика окрашены по тем же интервалам, индивидуальная
тренировочная зона выделена. В карточке пациента врач редактирует дату и длительность программы,
этапы с дневными нормами и параметры наблюдения; изменения применяются с текущего дня пациента.
В параметрах наблюдения врач задаёт отдельный верхний порог тренировочных минут за сутки
(1–1440 мин); пустое поле отключает проверку. Равенство порогу допустимо. При загрузке минут
и сохранении плана сервер проверяет итог дня и при превышении создаёт одно оповещение за день.
В журнале «Превышен порог тренировочных минут» показаны факт и порог на момент первого обнаружения;
последующие данные эту историческую запись не меняют. Пациент получает её при синхронизации.
Панель показывает выполнение нормы выбранного дня, минуты ходьбы без измеренного пульса и карту
всей программы со статусом каждого прошедшего дня. Журнал оповещений доступен в карточке
пациента и общей ленте `#/alerts`: в нём есть фильтр по виду, непросмотренные счётчики и отметка
отдельного оповещения просмотренным. Время событий и создания показывается в часовом поясе
пациента; рядом указаны задержка синхронизации и границы применения данных браслета.
В карточке «Пульс сейчас» врач может запросить непрерывное измерение на 1–60 минут (по
умолчанию 10): панель показывает ожидание телефона, выполнение, завершение, остановку пациентом
или понятную причину сбоя. Запрос попадёт на телефон при следующей синхронизации, обычно в
течение 30 минут; поступающие значения отображаются на том же графике последних пяти минут.

Сервер раздаёт собранную панель сам (`backend`, `KARDIO_FRONTEND_DIST`), поэтому для
демо хватает одного туннеля ngrok: панель и API — по одному адресу.

```bash
npm install
npm run build        # dist/ — его раздаёт сервер
npm run dev          # разработка: http://localhost:5173, /api проксируется на 127.0.0.1:8000
npm test
npm run typecheck
```

- Ссылка на пациента и день: `#/patients/<id>/<ГГГГ-ММ-ДД>`.
- Общий журнал оповещений врача: `#/alerts`. Журнал и счётчики обновляются автоматически;
    просмотренное оповещение не удаляется.
- Запрос непрерывного пульса (ТР-09): `POST …/live-heart-rate-requests`, состояние опрашивается
    через `GET …/live-heart-rate-requests/latest` раз в 2 с. Отмены со стороны врача нет; пациент
    останавливает измерение из постоянного уведомления на телефоне.
- Вход врача (ТР-11): форма входа → `POST /api/v1/auth/sign-in`, сеанс — cookie `HttpOnly`,
  скрипт панели её не видит. На `401` панель снова показывает форму входа. Аккаунт врача
  создаёт администратор сервера (`backend/README.md`).
- Контракт API — `backend/docs/api-contract.md` и Swagger `/docs` сервера.
