# ADR-0010: Программа реабилитации хранится версиями

- Статус: принято (2026-10-29)
- Дата: 2026-10-29

## Контекст

Врач меняет программу, этапы, нормы и параметры наблюдения во время курса. Правка действует с
текущего дня; прошлые дни оцениваются нормами, которые действовали в тот день (ТР-01, п. 8):
«сегодня день 10, норма 30 → 40 мин: дни 1–9 по 30, дни 10–15 по 40». При этом итог прошлого дня
может пересчитаться, если его минуты пришли поздно (ТР-03, п. 2), — значит, нормы прошлого дня
нужны и после правки.

## Решение

План реабилитации пациента `RehabPlan` — агрегат со списком версий `ProgramRevision`: день начала
действия, программа (начало, длительность, этапы с нормами) и параметры наблюдения. Правка
добавляет версию с сегодняшним днём пациента; вторая правка за день заменяет версию этого дня.
Нормы дня D — по версии с наибольшим днём начала, не позже D; день, которого нет в программе своей
версии, оценивается текущей. Хранение — таблица `rehab_plan_revisions`, этапы — JSON в строке
версии (читаются и пишутся только вместе с ней).

## Последствия

- Прошлые итоги не меняются от правки; итоги можно считать при чтении, без снимков.
- История правок норм видна (кто менял — журнал доступа ТР-11).
- Параметры наблюдения версионируются вместе с программой: порог ходьбы прошлого дня — тот, что
  действовал тогда. Дневные оповещения, включая `training_minutes_exceeded`, используют
  пороги версии дня события; «высокий пульс» — порог версии момента замера.
- Верхний порог тренировочных минут — `int | null` (1–1440), по умолчанию выключен.
  Превышение проверяет только дни программы своей версии, без переноса текущей программы на
  прошлый день. Полный итог перечитывается после любого upsert минут и при правке плана — за
  сегодня пациента. Снимок первого превышения неизменяем даже после исправлений и правки порога.

## Отвергнутые варианты

- Одна текущая программа + снимок итога каждого дня — поздние минуты требуют норм прошлого дня, а
  снимок появляется, только если день уже считался.
- Пересчитывать прошлое по новой программе — противоречит ТР-01, п. 8.
- Этапы отдельной таблицей — лишние соединения: этапы не живут без своей версии.
